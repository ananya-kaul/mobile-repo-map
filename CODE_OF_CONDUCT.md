# Code of Conduct

MobileRepoMap adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Please read it; it applies to everyone in every project space, including issues, pull requests, discussions and reviews.

In short: be welcoming and patient, assume good faith, give and accept constructive feedback gracefully, and focus on what is best for the community. Harassment, personal attacks, discriminatory language and publishing others' private information are not acceptable.

## Reporting

- **Non-sensitive concerns** can be raised in a [GitHub issue](https://github.com/ananya-kaul/mobile-repo-map/issues).
- **Anything sensitive or personal** should be reported privately through a [GitHub Security Advisory](https://github.com/ananya-kaul/mobile-repo-map/security/advisories/new), which is visible only to the repository maintainers. Mention that it is a Code of Conduct report.

All reports will be reviewed promptly and handled as confidentially as possible. The maintainer (@ananya-kaul) will follow the Contributor Covenant's enforcement guidelines when deciding on a response.
